# 2026-08-19 — OGE executive poll interval is 15 minutes

## Summary

The OGE executive watcher defaulted to 6 hours (`DEFAULT_POLL_INTERVAL_SEC = 21600`) as a politeness / "filings are rare" cadence.  That loses to other sources.  The product default is now **15 minutes (900 seconds)** so we beat other sources to new OGE Form 278-T filings.

Failed polls still wait **10 minutes** (`OGE_FAILURE_BACKOFF_SEC = 600`).  A down OGE index is not retried on every minutely cron tick.  House and Senate adaptive probe schedules are unchanged.

`pollIntervalSec` still reads Infisical first, then the env var, then this default.  A leftover Infisical / Coolify `OGE_POLL_INTERVAL_SEC=21600` keeps the old 6h cadence after deploy.  This repo does not write Infisical.  Set the live CT prod secret to `900`.
